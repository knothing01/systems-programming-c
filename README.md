# Systems Programming in C

Assignments and projects from Engineering 110 — foundational systems programming in C.

## Topics Covered

- Algorithms and complexity analysis
- Data structures (linked lists, stacks, queues, trees)
- Memory management and pointers
- File I/O
- Systems-level programming concepts

## Tech Stack

- C (C99/C11)
- GCC / Clang
- Make

## Build

```bash
gcc -o output <file>.c
./output
```
